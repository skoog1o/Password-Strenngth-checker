# Password Strength Checker

A beginner-friendly Python command-line program based on the **Strong Password Detection

## What it does

The program checks whether a password:
- Has at least 8 characters
- Contains an uppercase letter
- Contains a lowercase letter
- Contains at least one number

It gives the password a **Weak**, **Medium**, or **Strong** rating and lists which requirements were met. The original book exercise asks for the four checks above; the three-level rating is an extension.

## Requirements

- Python 3
- No third-party packages required

## Example


PASSWORD STRENGTH CHECKER
Enter a password to check:

Password strength: Strong

Security requirements:
  [PASS] At least 8 characters
  [PASS] Contains an uppercase letter
  [PASS] Contains a lowercase letter
  [PASS] Contains a number
